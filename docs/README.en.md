# Codex Request Optimizer

[简体中文](../README.md) · [English](README.en.md)

A Windows tool for viewing and optimizing Codex requests. Browse requests, token usage, and upload sizes by session, with lossless transport compression and protection against oversized requests.

[Download the latest Windows EXE](https://github.com/qzz1008-glitch/codex-request-optimizer/releases/latest) and double-click to run.
